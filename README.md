# fluid-sph-rain · Cesium流体模拟（高程驱动 + 降雨模拟增强版）

> 📖 **详细开发文档见 [DEVELOPMENT.md](DEVELOPMENT.md)** —— 架构设计、坐标约定、修复记录、测试体系、调参指南。

在 [少年啦1997] 的开源项目 fluid-sph 基础上增强：

- 着色器代码移植自 https://www.shadertoy.com/view/7tSSDD 及 https://www.shadertoy.com/view/l33Sz8
- 原始管线：固定 PNG 高程图 + 固定经纬度范围（`config.extent`）+ Cesium Primitive 自定义 DrawCommand 的 GPU SPH 流体模拟。

## 新增功能

### 1. 上传高程图，自动解析覆盖范围
- 顶部工具栏「📂 上传高程图」或 GUI「高程数据 → 上传高程图」，支持 `.tif / .tiff / .png / .jpg / .jpeg / .webp`。
- **GeoTIFF**：自动读取地理参考（ModelTiepoint / ModelPixelScale / GeoKeyDirectory），解析出经纬度覆盖范围，飞行定位并将高程图叠置显示在对应区域，绘制范围边框与标注。
  - **地理坐标系**（EPSG:4326 系）：包围盒直接作为经纬度范围。
  - **投影坐标系**（UTM、CGCS2000 高斯克吕格、Lambert 等）：通过 GeoKey 解析 + proj4 自动换算为经纬度后定位，无需手动放置。WGS84 UTM（EPSG:326xx/327xx）与中国 CGCS2000 系列（如 EPSG:4490 / 4547）均已覆盖；仅当缺少地理参考或换算失败时才降级为手动放置，并在状态栏说明原因。
  - 自动剔除 NoData 像元后再统计高程范围。
- **普通图片**：亮度即高程；自动检测并裁剪纯色/透明边框得到有效数据区，随后进入手动放置流程——在底图上单击一点作为中心，通过 GUI「放置宽度(km)」控制尺度（按纬度做经度缩放），放置时自动采样真实地形高程贴合地表。
- 基础地形数据：默认加载 ArcGIS 全球地形（WorldElevation3D，免 Token）；配置 `CESIUM_ION_TOKEN` 改用 Cesium World Terrain。底图默认 ArcGIS World 卫星影像，失败回退 OpenStreetMap → 无底图。
- 内置示例数据（加州 Tuolumne DEM）自动加载，但同样停在第 2 步"请划定模拟域"，需先划域才启动模拟。

### 2. 先划定任意多边形模拟域，水体被严格限制在域内
- 上传高程图后**不会立即启动模拟**：系统解析范围并把 DEM 叠置到地形上，状态栏提示「🗺 请划定模拟域」。
- 点击工具栏「🗺 划定模拟域」（或上传后自动进入）→ 左键在覆盖范围内逐点添加顶点，右键 / 双击 / 回车闭合（≥3 点），Esc 取消。橙色多边形即模拟域。
- 域掩膜（1024²）同时约束物理与渲染：**域外格子质量衰减 + 域边界速度反射 + 域外水面不渲染**。全域降雨也只往域内注水，域外绝不出水。
- 这是"先划域、再划雨区"流程的第一步，保证雨区严格落在域内。

### 3. 在模拟域内交互划定一个或多个降雨区域
- 「🌧 绘制降雨区域」进入绘制模式：左键添加顶点，右键 / 双击 / 回车结束，Esc 取消。**提交时校验所有顶点必须落在模拟域内**，否则拒绝并提示。
- 支持任意数量多边形雨区；每个雨区在 GUI「降雨控制」下有独立子面板：启用/停用、强度倍数（0~2）、删除，实体颜色轮换便于区分。
- 雨区多边形实时栅格化为 1024² 降雨掩膜纹理（重叠区取最大强度）。

### 4. 降雨区域累加雨量并实时驱动流体模拟
- SPH 模拟步中新增 `rainMask` 采样注入：`质量 += 降雨强度 × dt × 掩膜值`，
  注入的质量持续参与平流、地形梯度受力与渲染——即降雨累积 → 汇流 → 动态水面。
- 雨水"先附着地表、再汇聚流动"：
  - 模拟网格全覆盖初始化微量幽灵质量作为附着载体（原版仅 60% 格子有粒子），
    降雨可落在任意地表位置并逐渐积蓄成薄水层；
  - 降雨强度建议 0.003~0.02（GUI 上限 0.1）：强度过大时 SPH 压力项与质量平方成正比，
    薄层会失稳成尖刺，无法呈现贴地汇流形态。
- 「开始降雨」总开关、「降雨强度」全局滑杆、「全域降雨」一键对整个模拟范围降雨；
  「累计注入量」实时显示当前降雨过程的累积注入。
- 保留原版点击点源注水交互（需勾选「点源注水(点击生效)」）。

## 运行

```bash
# 任一静态服务器指向本目录即可，例如
npx http-server -p 8080          # 或 python -m http.server
# 浏览器打开 http://127.0.0.1:8080
```

需要 WebGL2 支持（Chrome / Edge 现代版本）。

**操作顺序（三段式）**：上传高程图 / 等示例加载 → ①「🗺 划定模拟域」画多边形 → ②「🌧 绘制降雨区域」在域内画雨区（或直接用「全域降雨」）→ ③ GUI「降雨控制」勾选「开始降雨」。水体严格限制在橙色模拟域内。

## 代码结构

```
index.html                     工具栏 / 状态栏 / GUI 宿主
index.js                       主控：数据流、放置流程、三段式模拟生命周期、GUI
src/sim/shaders.js             SPH 着色器（含 rainMask 降雨注入 + domainMask 域约束）
src/sim/geoUtils.js            经纬度 ⇄ 纹理UV ⇄ 画布像素 的统一换算约定
src/sim/rainMask.js            雨区多边形 → 降雨掩膜画布（lighten 合成）
src/sim/domainMask.js          模拟域多边形 → 域掩膜画布 + pointInPolygon 顶点校验
src/io/elevationLoader.js      GeoTIFF/普通图片解析与覆盖范围自动分析
src/io/projection.js           地理参考解析：GeoKey → proj4 → 经纬度覆盖范围
src/ui/domainEditor.js         模拟域（任意多边形）交互绘制与管理
src/ui/rainRegionEditor.js     降雨区域交互绘制与管理（含域内顶点校验）
src/render/FluidPipelineStages.js   原版 Compute/Volume 渲染阶段
libs/geotiff.min.js            GeoTIFF 解析库（jsdelivr 构建）
libs/proj4.js                  投影坐标系转换库（jsdelivr 构建）
static/1722500831109.png       内置示例高程图
```
